REQUIRED TEST CASES (from the project requirements, section 10)
-----------------------------------------------------------------------------

TC-01
  Scenario        : View all five routes and their seat status.
  Input / action  : Menu 1 -> "n" (show all routes) -> menu 9.
  Expected result : R101-R105 listed with seats 40/40, 36/36, 32/32, 45/45, 30/30,
                    all showing "Available".
  Actual result   : All five routes listed with exactly those seat counts; each
                    row showed status "Available".
  Status          : Pass

TC-02
  Scenario        : Search "Hyderabad" (departure OR destination).
  Input / action  : Menu 2 -> "Hyderabad" -> menu 9.
  Expected result : R101 (arrives), R103 (departs), R105 (arrives). Not R102, R104.
  Actual result   : Exactly R101, R103 and R105 were shown (route numbers 1, 3, 5).
                    R102 and R104 were not shown.
  Status          : Pass

TC-03
  Scenario        : Search an unknown city.
  Input / action  : Menu 2 -> "Atlantis" -> menu 9.
  Expected result : No-match message; program continues to the menu.
  Actual result   : Printed "No match found for 'atlantis'. Try a route ID like
                    R101 or a city like Karachi." and the menu appeared again.
  Status          : Pass

TC-04
  Scenario        : Book two seats on R101 with valid details.
  Input / action  : Menu 3 -> name "Ali Khan", age 30, route R101, seats 2.
                    Then menu 6 -> "n".
  Expected result : Booking B1001 Confirmed, total fare Rs. 2,400, R101 seats 40 -> 38.
  Actual result   : "Booking successful!" with Booking ID B1001, Fare per seat
                    Rs. 1,200, Total fare Rs. 2,400, Status Confirmed.
                    Seat availability then showed R101 = 38 of 40, "Partially Booked".
  Status          : Pass

TC-05
  Scenario        : Attempt to book zero seats.
  Input / action  : Menu 3 -> "Ali Khan", 30, R101, seats 0. Then menu 4 and menu 6.
  Expected result : Rejected; no booking record; seats unchanged at 40.
  Actual result   : Printed "Booking failed: number of seats must be a whole number
                    greater than 0." View bookings said "No bookings found."
                    R101 still 40 of 40, "Available".
  Status          : Pass

TC-06
  Scenario        : Request more seats than available.
  Input / action  : Menu 3 -> "Ali Khan", 30, R101, seats 41. Then menu 4 and menu 6.
  Expected result : Rejected; availability not negative; no booking.
  Actual result   : Printed "Booking failed: you asked for 41 seat(s) but only 40
                    are available." No bookings found; R101 still 40 of 40.
  Status          : Pass

TC-07
  Scenario        : Cancel a confirmed booking.
  Input / action  : Book 2 seats on R101 (B1001) -> menu 5 -> B1001 -> menu 4 -> menu 6.
  Expected result : Status becomes Cancelled; seats restored 38 -> 40; record kept.
  Actual result   : "Booking B1001 has been cancelled." Seats returned: 2; seats now
                    40/40. Booking list still showed B1001 with status Cancelled.
                    R101 back to "Available" (40 of 40).
  Status          : Pass

TC-08
  Scenario        : Cancel the same booking again.
  Input / action  : Book 2 seats (B1001) -> cancel B1001 -> cancel B1001 again -> menu 6.
  Expected result : Second cancel rejected; seats NOT restored twice (stay 40, not 42).
  Actual result   : Second attempt printed "Cancellation failed: booking B1001 is
                    already Cancelled. No seats were changed." R101 stayed 40/40.
  Status          : Pass

TC-09
  Scenario        : Generate report with no bookings.
  Input / action  : Menu 7 -> menu 9 (no bookings made).
  Expected result : All counts, reserved seats and revenue are zero.
  Actual result   : Total bookings 0, Confirmed 0, Cancelled 0, Seats currently
                    reserved 0, Confirmed revenue Rs. 0, Fully booked routes 0.
  Status          : Pass

TC-10
  Scenario        : Book exactly all remaining seats.
  Input / action  : Book 2 seats on R101, then book 38 seats on R101 (the rest),
                    then menu 6.
  Expected result : Both bookings succeed; R101 becomes Fully Booked with 0 seats.
  Actual result   : Both showed "Booking successful!" (second total fare Rs. 45,600).
                    Seat availability showed R101 = 0 of 40, "Fully Booked".
  Status          : Pass

TC-11
  Scenario        : Report after a cancellation; cancelled fare excluded.
  Input / action  : Book 2 seats R101 (B1001, Rs. 2,400); book 1 seat R102 (B1002,
                    Rs. 2,000); cancel B1001; menu 7.
  Expected result : Total 2, Confirmed 1, Cancelled 1, reserved seats 1,
                    revenue Rs. 2,000 (the cancelled Rs. 2,400 is excluded).
  Actual result   : Total bookings 2, Confirmed 1, Cancelled 1, Seats currently
                    reserved 1, Confirmed revenue Rs. 2,000, Fully booked routes 0.
  Status          : Pass

TC-12
  Scenario        : Invalid menu text / numbers.
  Input / action  : At the menu type: abc, 10, 0, (empty Enter), -1, 2.5, then 9.
  Expected result : Helpful error each time, no crash, menu returns, 9 exits.
  Actual result   : "abc", empty, "-1" and "2.5" printed "Invalid input: please type
                    a number from 1 to 9."; "10" and "0" printed "Invalid choice:
                    please pick a number from 1 to 9." No crash; 9 printed Goodbye.
  Status          : Pass
